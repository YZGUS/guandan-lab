# Web 验收问题修复与复验

本记录对应 `WEB_ACCEPTANCE_2026-09-27.md` 中发现的问题。原报告保留作为修复前基线。

## 修复结果

| 问题 | 修复 | 复验 |
| --- | --- | --- |
| 局域网 HTTP 出牌/不要报错 | 动作 ID 改用 HTTP 下可用的 `crypto.getRandomValues` | 真实 LAN IP 页面：手动出牌26→25，无异常；不要26→26并转交牌权 |
| QQKKAA / KKKAAA 被拒绝 | 由点数表长度计算完整连续窗口 | 固定牌例通过；所有级牌下生成/校验一致性检查通过 |
| 百搭提示选牌后无法出牌 | 枚举所有合法解释；提示保留牌型声明，手选按当前目标过滤 | 打10时5678+♥10压45678：提示声明到9，按钮可用，服务器接受，5张手牌出完 |
| 无法选择百搭解释 | 合法解释超过一个时展示选项 | 自由领出同一组牌，可选到8或到9；选择到9后服务器成功扣除5张 |
| 未打 A 即获胜 | 必须本副级牌A、胜方等级A，且搭档非末游 | 未实际打A的状态留在A，下一副实际打A；双方均到A的合理获胜仍通过 |
| 双贡同点先手 | 明确头游下家先贡给头游并先手，不按实体ID排序 | 固定seed=1、头游2号位时由3号位先手，108张牌与四家27张守恒 |
| 小屏横屏裁牌 | 手牌行自适应列间距，最后一张保留完整宽度；牌桌区与手牌区独立分配高度 | 667×375及其他6种尺寸，无手牌裁切；短横屏北/南家与中央出牌区无交叠 |
| 开局后无法离桌 | 确认后Bot接管原手牌；房主转交剩余真人；最后真人离开关闭房间 | 服务端验证接管后牌张不变；浏览器验证取消离桌与确认返回大厅 |
| 整场后无法返回/再来一局 | 结算提供返回大厅；房主可回到等待室重开 | 构造整场结束状态进行真实UI测试：保留房间及四席，重开从2开始，每人27张 |
